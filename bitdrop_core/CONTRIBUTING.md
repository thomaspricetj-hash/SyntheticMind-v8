Thank you for your interest in contributing to the BitDrop GPU Compression Engine. BitDrop is an open project under the GPLv3 license, and contributions that improve performance, stability, documentation, or usability are welcome. Before submitting changes, please make sure you have a working build of the project using the standard CMake and Visual Studio toolchain. All contributions should maintain the structure‑of‑arrays layout, the rule‑based masking system, and the deterministic behavior of the compression and decompression kernels. If you are modifying CUDA kernels, ensure that your changes compile under NVCC, match the function signatures defined in the public headers, and do not introduce undefined behavior or race conditions. Any performance‑related changes should be benchmarked using the included bdrop\_bench tool, and results should be included in your pull request so maintainers can verify improvements. If you add new features, please update the documentation and provide clear explanations of how the new functionality integrates with the existing API. All code submissions must follow the GPLv3 license, and by contributing, you agree that your work will be released under the same license. If you find bugs, security issues, or unexpected behavior, please open an issue with clear reproduction steps and system details. Contributions should be submitted through GitHub pull requests, and maintainers may request revisions to ensure code quality and consistency. Thank you for helping improve BitDrop and supporting high‑performance open GPU computing.
