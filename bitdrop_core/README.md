BitDrop is a high‑performance GPU compression engine designed for AI systems that need extremely fast, structure‑aware masking and data reduction. It uses a fused‑mask collapse kernel optimized for modern NVIDIA GPUs and has been benchmarked at over 102 GB per second on an RTX 4090. The system operates on a structure‑of‑arrays layout and supports headers, multiple auxiliary streams, graph data, and payload data. BitDrop includes a CUDA compression kernel, a matching decompression kernel, a rule‑based masking system, and a benchmark tool. The project is organized into a source directory containing the CUDA kernels and host API, an include directory with public headers, and a tools directory containing the benchmark program. To build the project, create a build directory, run CMake to generate Visual Studio project files, and compile in Release mode. After building, you can run the benchmark executable to measure throughput. BitDrop is designed to integrate easily into AI pipelines, and a separate installation guide explains how to allocate buffers, upload rule banks and level masks, and launch the compression and decompression kernels. The project is intended for developers who want extremely high‑throughput GPU‑based compression inside machine learning or data‑processing systems.
